# E-Commerce Customer Analysis

## Real-world problem

An e-commerce company wants to understand customer behavior.

## Data Mining Flow

**Customer Data**

↓

**Data Collection**

↓

**Data Understanding**

↓

**Data Analysis**

↓

**Statistical Analysis**

↓

**Customer Segmentation**

↓

**Business Insights**

↓

**Business Decision**

## We need to find out:

* Average spending
* Highest and lowest spending
* Total revenue
* High-value customers
* Frequent customers
* Relationship between orders and spending

## Statistical functions used

| Requirement        | Function   |
| ------------------ | ---------- |
| Average            | `mean()`   |
| Total              | `sum()`    |
| Highest            | `max()`    |
| Lowest             | `min()`    |
| Middle value       | `median()` |
| Variation          | `sd()`     |
| Relationship       | `cor()`    |
| Customer selection | Filtering  |
